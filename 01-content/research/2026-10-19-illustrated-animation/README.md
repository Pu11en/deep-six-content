# Illustrated fire-ant video: first choice

**Try the [Claude Animation drawing kit](https://github.com/buildwithhanif/claude-animation-skill) first.** It has code for textured ants, soil and underground rooms—the closest starting material I found for your illustrated science-book direction. This recommendation is based on source review; a new render remains untested.

## The first trial

Make a **10–15-second vertical scene** showing workers moving their young through a nest. Use a matching excerpt from your approved Tyler recording, Deep Six colors, and **Astra with ultra effort**. This would test the drawing, movement and educational clarity before making the full 79-second video.

Node and FFmpeg are already installed here. The kit and its drawing dependency still need installing. [Future setup checklist](first-trial-plan.md).
