# How these hooks are made

**The current writer uses basic attention patterns. The fuller method below is a proposal for strengthening that process.**

This batch used the checked wasp facts, your earlier feedback, one approved narration and four opening patterns: a visible problem, a question, a surprising fact or a misconception. GPT-6 Astra wrote the choices. The reviewed video-example library contains zero examples.

For stronger openings, I recommend:

1. **Surprise:** begin with a concrete, unexpected fact.
2. **Curiosity:** leave a specific question the viewer wants answered.
3. **Clarity:** make the subject understandable without specialist terms.
4. **Payoff:** deliver the promised explanation in the narration.

This adapts the surprise, intrigue and satisfaction approach described in [YouTube's conversation with creator Jenny Hoyos](https://blog.youtube/creator-and-artist-stories/youtube-shorts-deep-dive/). I checked the published article, not the interview video.
